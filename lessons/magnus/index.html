About the model

The flow is ideal 2-D potential flow (uniform flow + doublet + vortex). Circulation uses Γ = 2π r² ω, limited to 4π r V. Real cylinders make less lift because of viscosity, so treat the numbers as an upper limit. The wake shape is a simple visual model.

Cylinder radius 5 cm, air density 1.225 kg/m³ (ISA sea level). All values and sources are in src/config/magnus.ts.
